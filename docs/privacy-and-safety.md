# Privacy and safety boundaries

- Keep personal profiles, identity numbers, phone numbers, email addresses, resumes, real job workspaces, drafts, and generated proposals out of this repository.
- Job capture must show the extracted source text for review before it is retained by JobSeekingOS.
- Application-form assistance may prepare ordinary fields but must preserve existing values and surface uncertain mappings for manual review.
- Attachments, identity declarations, consent checkboxes, draft saving, and final submission require a separate explicit user action.
- Matcher reads only a confirmed profile version and writes a pending proposal. It never changes application intent or workflow state.
- Salary research distinguishes sourced facts, estimates, and unknowns. It never contacts a recruiter, quotes a number, or accepts or rejects an offer.
