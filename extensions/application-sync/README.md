# JobSeekingOS 网申同步助手（本地验证版）

从 `http://127.0.0.1:4173/jobs` 的**已确认网申档案**读取可复用事实。打开企业招聘表单后，点击扩展图标和「自动填写网申」；扩展保留已有内容，尝试填写文本、多条经历、明确对应的选项与完整年月，并在网页右下角报告仍需核对的字段。

身份证号默认不读取。本次要填入当前网站时，须在扩展中单独勾选。证件照、附件、密码、验证码、Cookie 和隐藏令牌不进入自动填写；扩展不会勾选诚信声明或提交申请。企业及岗位专属问题由本人在当次网申处理。

档案中的奖项名称、时间和描述分别保存。企业网站只有「描述该荣誉或奖励」时，优先映射档案里的奖项描述；描述为空时填奖项名称，不附加获奖年份。日期缺少明确年月时不猜测；选项找不到明确对应值时留空提示。

## 本地使用

1. 在 4173/jobs 中维护并确认网申档案，保持该页面打开。
2. Safari 可通过开发菜单加载解压后的临时扩展目录；源码 ZIP 由 4173 的网申同步助手页面提供。只在开发时修改了扩展代码后，才到 Safari 扩展设置点「重新加载」。
3. 在企业招聘表单页点击扩展图标，核对网站域名，按需决定是否单独授权身份证号，点击「自动填写网申」，填写完成前保持扩展面板和招聘页面打开。
4. 查看页面右下角结果，逐项核对，再由本人决定是否暂存或提交。

Chromium 可在扩展管理页使用「加载已解压的扩展程序」选择本目录。不同浏览器的本地档案不自动共享。

## 验证

字段计划和关键限制经过主项目模拟测试；源码检查不能替代真实网站的读回核对。

当前版本 v0.5.11，实验性源码发布。Moka 仅尝试部分文本字段；国家、籍贯、年月及多条教育经历仍需人工核对填写。此版本修复了执行失败信息被吞掉的问题，尚未完成 Safari 真实表单回归。

需要本机运行 JobSeekingOS（127.0.0.1:4173）并确认档案；不能直接连接公开展示站。仓库不包含工作台服务或个人数据。源码 ZIP 不是 Safari 签名安装包。
