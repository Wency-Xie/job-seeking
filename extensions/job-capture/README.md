# JobSeekingOS 官网岗位采集

Safari 扩展（WebExtension）源码。药明康德、华大 BGI、Moka、仟寻页面使用专用识别规则；其他 HTTPS 招聘页面尝试通用提取，并在核对面板标明「未验证来源」。打开并展开目标岗位后点击扩展；华大列表有多个已展开岗位时，会预选视口顶部可见岗位，仍须核对岗位编号，必要时从下拉列表改选。对照原页核对公司、职位、Base、批次、编号、完整 JD 和来源；公司、职位、HTTPS 来源和至少 30 字 JD 是保存必填项，其他字段可待补。确认后保存到候选岗位优先级视图。

开发安装：解压源码到固定目录，通过 Safari 开发菜单加载临时扩展；修改源码后，并在 Safari「设置 → 扩展 → JobSeekingOS 官网岗位采集」点击「重新加载」。已打开的核对面板仍保留旧内容，需要关闭并重新点击扩展采集。JobSeekingOS 须运行在 `127.0.0.1:4173`。通用提取仍需逐页验证，BOSS、公众号等平台可能因为页面结构、登录状态或动态加载而只得到部分字段。

2026-09-30 增补：字节跳动职位详情页和 BOSS 移动职位页加入定向提取，按职位描述／要求与相关职位、工作地点等章节边界截取当前 JD。两页目前只有结构样本回归测试，Safari 实页结果仍需重新加载扩展并核对；其他官网继续走通用回退，不代表全站支持。

## 版本与依赖

v0.4.0，实验性源码发布。新增 TypeScript 岗位字段契约，将北森、Moka、Moseeker 和通用页面的提取结果归一化为统一字段，同时保留 4173 当前使用的兼容字段。TypeScript 编译成功只证明数据结构通过检查，不代表任何招聘平台已经完成实站验收。

插件默认连接 `127.0.0.1:4174` 开发测试工作台；只有在核对面板中明确选择 `4173 · 个人验收` 时才连接个人工作台。开发测试通过不自动写入 4173。需要本机运行对应的 JobSeekingOS 服务，不能直接连接其他人的工作台或公开展示站。源码下载不等同于 Safari 签名安装包。Chrome/Edge 可尝试加载解压目录，尚未完成跨浏览器验收。

重新生成运行文件：

```bash
tsc -p extensions/job-capture/tsconfig.json
```

## 隐私

只在用户点击后读取当前页面岗位内容，核对后发送到本机工作台。仓库不包含个人档案、求职记录或后台服务。
