# JobSeekingOS 官网岗位采集

Safari、Chrome 和 Edge 共用的 WebExtension 源码。药明康德、华大 BGI、Moka、仟寻页面使用专用识别规则；其他 HTTPS 招聘页面尝试通用提取，并在核对面板标明“未验证来源”。

打开并展开目标岗位后点击扩展。唯一识别到一个岗位时，扩展直接在网页右侧打开核对栏；识别到多个岗位时，弹窗要求先选择。对照原页核对公司、职位、Base、批次、编号、完整 JD 和来源，点击“核对无误”后打开 JobSeekingOS 导入页查重。没有重复岗位时直接加入候选；发现疑似重复时先选择关联。

## 开发者模式安装

三个浏览器加载同一份解压目录。先把 `job-capture-extension-source.zip` 解压到固定位置，并选择其中包含 `manifest.json` 的文件夹。

### Safari

1. 通过 Safari 开发菜单加载解压后的扩展目录。
2. 在“设置 → 扩展 → JobSeekingOS 官网岗位采集”中启用扩展。
3. 源码更新后在同一页面点击“重新加载”。已打开的核对面板仍是旧内容，需要关闭后重新采集。

### Chrome

1. 打开 `chrome://extensions`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的扩展目录。
4. 源码更新后回到扩展管理页，点击扩展卡片上的“重新加载”。

### Edge

1. 打开 `edge://extensions`。
2. 开启“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择包含 `manifest.json` 的扩展目录。
4. 源码更新后回到扩展管理页，点击扩展卡片上的“重新加载”。

安装后确认扩展版本为 `0.5.0`。浏览器兼容不代表每个招聘网站都已验证；BOSS、公众号等平台可能因为页面结构、登录状态或动态加载而只得到部分字段。

## 版本与依赖

v0.5.0，实验性源码发布。扩展使用 Manifest V3、`activeTab`、`scripting` 和 `tabs` 权限。TypeScript 岗位字段契约把北森、Moka、Moseeker 和通用页面的提取结果归一化为统一字段，同时保留 4173 当前使用的兼容字段。TypeScript 编译成功只证明数据结构通过检查，不代表任何招聘平台已经完成实站验收。

插件默认连接 `127.0.0.1:4173` 个人工作台；需要隔离验证时，可在扩展弹窗中明确切换到 `4174 · 开发测试`。开发测试数据不会自动写入 4173。需要本机运行对应的 JobSeekingOS 服务，不能直接连接其他人的工作台或公开展示站。

重新生成运行文件：

```bash
tsc -p extensions/job-capture/tsconfig.json
```

## 隐私

扩展只在用户点击后读取当前页面岗位内容，核对后发送到本机工作台。仓库不包含个人档案、求职记录或后台服务；扩展不会自动投递、联系招聘方或推进岗位流程。
